# CommunityViewer 웹버전

[웹버전 열기](https://kwww-aniki.github.io/CommunityViewer-Web/)

자주 보는 커뮤니티 게시판을 한곳에 모아두는 웹앱입니다. 사이트와 구역을 찾아 게시판을 즐겨찾기에 추가하세요. 게시판을 누르면 해당 사이트가 새 탭에서 열립니다.

## 주요 기능

- 18개 사이트의 게시판 검색과 즐겨찾기
- 게시판 주소 직접 추가
- 즐겨찾기 순서 변경
- JSON 파일로 즐겨찾기 백업·복원
- 휴대폰 홈 화면에 웹앱 추가

즐겨찾기는 현재 브라우저에 저장됩니다. 다른 휴대폰이나 브라우저로 옮길 때는 **더보기 → 백업 파일 저장/불러오기**를 사용하세요. Android 앱의 `CommunityViewerFavorites` 백업 파일도 불러올 수 있습니다.

웹브라우저에서는 다른 사이트의 화면을 앱 안에 표시하거나 광고를 숨기는 기능을 제공하지 않습니다. 게시판 내용은 원래 사이트에서 열립니다.
